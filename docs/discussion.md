# ตอบคำถาม

ตะกร้าสินค้ามีหลาย action ได้แก่ ADD, REMOVE, INCREASE, DECREASE, CLEAR ถ้าใช้ useState ต้องเขียนฟังก์ชันแยกหลายตัว แต่ useReducer รวม logic ทั้งหมดไว้ใน Reducer Function เดียว ทำให้โค้ดอ่านง่ายและจัดการได้ดีกว่า

______________________________________________________________________________

## ข้อ 2: useMemo ช่วยเพิ่มประสิทธิภาพของระบบอย่างไร

useMemo จำผลลัพธ์การคำนวณไว้และคำนวณใหม่เฉพาะเมื่อ dependency เปลี่ยน ในระบบนี้ใช้กรองเมนูและคำนวณราคารวม ทำให้ไม่ต้องคำนวณซ้ำทุกครั้งที่ Component render

______________________________________________________________________________

## ข้อ 3: useCallback มีประโยชน์ในสถานการณ์ใด และหากไม่ใช้จะเกิดผลอย่างไร

useCallback มีประโยชน์เมื่อส่งฟังก์ชันเป็น props ให้ Component ลูก ถ้าไม่ใช้ ฟังก์ชันจะถูกสร้างใหม่ทุกครั้งที่ render ทำให้ Component ลูก render ซ้ำโดยไม่จำเป็น

______________________________________________________________________________

## ข้อ 4: เปรียบเทียบการใช้ useContext กับการส่งข้อมูลผ่าน Props (Props Drilling)

| หัวข้อ       | Props Drilling    |   useContext            |

| ความซับซ้อน  | สูง ส่งหลายชั้น      |   ต่ำ เข้าถึงได้ทันที         |
| การอ่านโค้ด   | ยาก              |   ง่าย                    |
| เหมาะกับ     | ข้อมูลไม่กี่ชั้น        |  ข้อมูลที่ใช้หลาย Component |

useContext เหมาะกับโปรเจคนี้เพราะข้อมูลตะกร้าต้องใช้หลาย Component พร้อมกัน
